# 🏏 Sri Lanka Cricket Performance Analysis

## 📌 Project Overview
This Power BI dashboard provides a deep-dive into Sri Lanka's Win/Loss records, Toss impact, and player performance from 2003 to 2026.

## 🛠️ Key Insights
- Sri Lanka wins **46%** of matches played at Home vs **40%** Away.
- The most frequent "Player of the Match" is **KC Sangakkara (Kumara Sangakkara)**.
- Winning the toss leads to a **43%** win probability.
